# Onze Mobile

Aplicativo mobile do **Onze — Organizador de Pelada**.

## Stack

- React Native
- Expo
- TypeScript
- Expo Router

## Branches

- `master`: versão estável
- `development`: integração e validação
- `feature/*`: desenvolvimento por funcionalidade

## P0

Fundação técnica do aplicativo Android, incluindo estrutura inicial, CI e geração de APK de teste.
